# Set-Up

To start, we opened JupyterLab and copied the link from the terminal output which contained the token.

We were presented with a template including an implementation of a `Base` class, as well as a `GPIB` class. 
These represent the physical set-up of the measuring devices, since each device is accessed using the computer via a GPIB and a device-specific address.

We refactored the Base and GPIB classes which were given in the template.
