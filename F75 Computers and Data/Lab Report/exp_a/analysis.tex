\subsection{Experiment A}

The resonance curve of the vibrating reed was measured around the first three harmonic frequencies.
\num{20} independent measurements of the amplitude/phase shift/$X$/$Y$ were taken at each frequency, then immediately averaged, with standard deviation taken to be the error.
These datasets were saved to text files for analysis.
In our analysis code we read in the data again.
The measurements are plotted against frequency and displayed in \autoref{fig:analysis_exp_a}.

In the graphs we also plot the \quotedef{target frequency} around which the peak is expected to be.
Lastly, we use regression (least squares/parametric $\chi^2$ fit) to fit a Lorentz curve (see \autoref{eq:analysis_lorentz}) to the resonance peak for each dataset.
The resulting parameters are given in \autoref{tab:analysis_params_a}.

\begin{gather}
    \omega = 2 \pi f \\
    A(\omega) = \frac{f_0}{\sqrt{(\omega_0^2 - \omega^2)^2 + \gamma^2 \omega^2}}
    \label{eq:analysis_lorentz}
\end{gather}

These parameters are found by minimizing the \( \chi^2 \) value, which represents the size of the residuals of the data points (how far the model is from the data).
It is useful to visualize the residuals as well, so these are shown in \autoref{fig:analysis_exp_a_residuals}.
Minimizing the \( \chi^2 \) value is equivalent to maximizing the likelihood that the data comes from the created model.
Another way to understand how well the model fits the data is by calculating the $p$-value.
This is the probability that results with residuals at least this large are obtained in the experiment, assuming the data comes from this model.
In other words, it represents the probability that we get results at least this \quoteapprox{extreme}.
The fit statistics are given in \autoref{tab:analysis_stats_a}.

Finally, we examine the quality of the resonator (the $Q$-factor).
This can be calculated through \autoref{eq:analysis_a_q_factor_theo} or by measuring the full-width-half-maximum ($\FWHM$) of the experimentally measured curve (see \autoref{eq:analysis_a_q_factor_exp}).
Both of these are calculated/measured and reported in \autoref{tab:analysis_Q_a}.
In this table we also include the $\sigma$-deviation between the two values.

\begin{gather}
    Q = \frac{\omega_0}{\gamma}
    \label{eq:analysis_a_q_factor_theo} \\
    Q \approx \frac{\omega_R}{\FWHM}
    \label{eq:analysis_a_q_factor_exp} \\
\end{gather}
